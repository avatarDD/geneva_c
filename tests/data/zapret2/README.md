# Payloads from zapret2

UDP and TCP payloads from `files/fake/` of zapret2
(https://github.com/bol-van/zapret2, commit `038c97e`, MIT, see `LICENSE`).
Test data only: the L7 parsers, the QUIC Initial decryption and the lab
censors are checked against real client packets. They are not built into
geneva.
