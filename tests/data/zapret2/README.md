# Payloads from zapret2

All of `files/fake/` of zapret2 (https://github.com/bol-van/zapret2, commit
`038c97e` = v1.0.7, MIT, see `LICENSE`). Test data only: the L7 parsers
(`tests/data/l7_expected.txt`), the QUIC Initial decryption and the lab
censors are checked against real client packets. They are not built into
geneva.
