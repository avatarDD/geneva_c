$ $G --help
geneva VERSION - genetic censorship evasion (C port of Geneva)

Usage: geneva <command> [options]

Commands:
  agent      run the probes of a server-side evaluation (no root)
  apply      run a strategy over a pcap file offline
  censor     run one of Geneva's lab censors on a Linux router
  check      parse, validate and print strategies
  ctl        talk to a running engine over its control socket
  db         list, rank, export and prune the strategy database
  eval       evaluate strategies against a target with a probe
  evolve     search for strategies with the genetic algorithm
  fw         print, apply or remove the firewall rules of run
  library    list the built-in strategies of Geneva's library
  run        apply a strategy to live traffic (NFQUEUE, WinDivert or divert)
  version    print version and build features

Run "geneva <command> --help" for command options.

Extensions (with --ext):
  --ext after a command turns on the extensions beyond Geneva:
  censor models 12-20 (geneva censor --ext --list); triggers FLOW:,
  META: and L7: ([L7:host:example.com]-drop-|); x-actions after zapret2's
  functions, NAME{key=value;...}: xfake xsplit xdisorder xtcpseg xhostfake
  xfakedsplit xfakeddisorder xsend xmod; xsyndata xrst xsynack xsynacksplit
  xwsize xwssize; xhttp{domcase;hostcase=hoSt;methodeol;unixeol}; xudplen
  xdhtdn; xtlsclone (a changed copy of the ClientHello as a blob for the
  actions after it); xtag (an own payload label); xlog (event ext_pkt);
  xpcap{file=...}; combinators after zapret2's orchestrators:
  xwhen{iff=COND;neg}(then,else), xstop{iff=COND}(rest),
  xrepeat{repeats=N;iff=COND;stop}(body,rest), xcutoff{dir=in|out|both};
  COND is cond_random (percent=P), cond_payload_str (pattern=TEXT),
  cond_tcp_has_ts, cond_true, cond_false or a trigger such as FLOW:n:<5
  or L7:payload:http_req, e.g.
  [TCP:flags:PA]-xfake{blob=fake_default_tls;ttl=3}(xdisorder{pos=1,midsld},)-| \/
  [TCP:flags:PA]-xtlsclone{blob=c;sni_first=a.example}(xfake{blob=c;ttl=3},)-| \/
  [TCP:flags:PA]-xwhen{iff=FLOW:n:<3}(xrepeat{repeats=2}(xfake{blob=0x41;ttl=1},),)-| \/
  xoob{urp=b|e|MARKER;char=C|byte=N} (an urgent byte) and xtlsrec{pos=MARKER}
  (the TLS record cut in two) make the first message longer: they must see
  the flow from its SYN, whose seq they shift, and incoming packets must
  reach the queue until the server acks the message (its acks are mapped
  back, its retransmissions sent again changed); xdrip{n=N;delay=MS} sends
  the first N bytes one per segment with pauses, e.g.
  [FLOW:n:1-]-xoob{urp=e}-| \/   [FLOW:n:1-]-xtlsrec{pos=sniext+1}-| \/
  geneva CMD @FILE takes the options from FILE (with --ext); run --ext also
  has --dry-run, --daemon, --pidfile, --user/--uid, seccomp and syslog.
  geneva selftest --ext --fuzz N runs every reader of packets, captures,
  strategies, lists and profiles over N random inputs (selftest --help).
  geneva resolve --ext < NAMES resolves a list with threads (zapret2's mdig),
  geneva ip2net --ext < ADDRESSES groups addresses into subnets (zapret2's
  ip2net); see their --help.
  geneva blockcheck --ext [DOMAIN...] runs zapret2's blockcheck2: each test
  (http, tls12, tls13, http3) without a strategy, then the strategies of
  blockcheck2.d/standard translated into geneva, scan levels, the report
  SUMMARY / COMMON / COVERAGE with nfqws2 and geneva strategies side by side
  (blockcheck --help; --print-grid lists the grid without probes).
  Obfuscation of zapret2's zapret-obfs.lua, the same action on both ends
  (outbound forest here, inbound there): xwgobfs{secret=S;padmin;padmax}
  (WireGuard handshakes encrypted, AES-GCM), xippxor{ippxor=N;dataxor=BLOB}
  (the IP protocol number XOR N), xudp2icmp{server=0|1;ctype;stype;ccode;
  scode;dataxor;cgnat;id_lifetime} (UDP as ICMP echo; cgnat survives a NAT
  that changes the identifier), xsynhide{magic=x2|urp|opt|tsecr;ghost;
  synack;xorseq} (the SYN sent as a marked ACK), e.g.
  [UDP:dport:51820]-xwgobfs{secret=S}-| \/ [UDP:sport:51820]-xwgobfs{secret=S}-|
  See docs/EXT.md.

      --mark MASK                fwmark of the packets the censor sends (default 0x20000000)
      --firewall TYPE            auto, nft, iptables, or none (rules set up by hand)
  -i, --iface IF                 only packets that arrive on this interface
      --duration SEC             stop after SEC seconds

Signals: SIGHUP re-reads --strategy-file, SIGUSR1 emits stats,
