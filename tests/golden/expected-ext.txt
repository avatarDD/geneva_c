### help-ext-censor
$ $G censor --help
Usage: geneva censor -c NAME [options]
Runs a lab censor of Geneva on a Linux router: packets forwarded to and from
PORTS pass through it. Needs root. SIGHUP resets the censor's state (Geneva
starts a fresh censor for every strategy); SIGINT/SIGTERM stop it and
remove the firewall rules. See docs/CENSOR.md.

Options:
  -c, --censor NAME              censor model: 1-11, 8b or dns (see --list)
      --list                     list the censor models
  -p, --port PORTS               ports of the censored service (default 80; dns: 53)
  -w, --forbidden WORD           forbidden content (repeatable; default ultrasurf)
      --censor-ip ADDR           source of RSTs to the server: client (default), router (as Geneva) or an address
      --dns-answer ADDR          dns: forged A or AAAA answer (default 10.10.34.34, 2001:db8::34)
  -q, --queue N                  NFQUEUE number (default 400)
      --mark MASK                fwmark of the packets the censor sends (default 0x20000000)
      --firewall TYPE            auto, nft, iptables, or none (rules set up by hand)
  -i, --iface IF                 only packets that arrive on this interface
      --duration SEC             stop after SEC seconds
  -e, --events SINK              JSON Lines events: - (stdout), stderr, FILE or none
  -l, --log-level LEVEL          error, warn, info (default), debug or trace
      --log-format FMT           text (default) or json
      --log-file FILE            also write the log to FILE
  -v, --verbose                  same as --log-level trace
      --quiet                    no log on stderr
  -h, --help                     show help

Extensions (with --ext):
      --ext                      turn on the extensions: models 12-20 (--ext --list)
      --freeze-bytes N           censor 12: bytes to the client before the freeze (16384)
      --rate BPS                 censor 13: bytes per second to the client (16384)
      --burst BYTES              censor 13: bucket depth in bytes (32768)
      --rst-ttl N                censor 14: TTL of the injected RSTs (64)
      --min-ttl N                censor 19: packets below this TTL are not inspected (2)
      --redirect URL             censor 18: Location of the 302 (http://block.example/)
      --block-ip ADDR            censor 17: blocked address, repeatable (up to 16)

Usage: geneva run -s STRATEGY -p PORTS [options]
Applies a strategy to live traffic: NFQUEUE on Linux (root), WinDivert on
Windows (Administrator, WinDivert.dll and WinDivert64.sys next to geneva.exe).
Signals: SIGHUP re-reads --strategy-file, SIGUSR1 emits stats,

  -s, --strategy STRATEGY        strategy to run

      --server-side              run on the server: outbound packets come from PORTS
      --proto LIST               tcp, udp or tcp,udp (default tcp)
  -q, --queue N                  NFQUEUE number (default 310)
      --mark MASK                fwmark bit of packets the engine sends itself (default 0x20000000)
      --firewall TYPE            auto, nft, iptables, or none (rules set up by hand)
  -i, --iface IF                 only traffic through this interface (the WAN on a router)
      --dir both|out|in          directions to intercept (default both)
  -4, --ipv4-only                handle IPv4 only
  -6, --ipv6-only                handle IPv6 only
      --first N                  apply the strategy to the first N packets of each connection per direction
      --prenat                   nft: intercept outgoing packets before SNAT (default after)
      --no-notrack               leave packets the engine sends in conntrack
      --no-bypass                drop instead of pass traffic while no engine listens
      --forward-to ADDR          Geneva forwarder: DNAT the ports to ADDR and masquerade
      --filter EXPR              Windows: WinDivert filter to capture, replaces the one from -p/--proto/--dir
      --filter-file FILE         Windows: read the --filter expression from FILE (up to 64 KB)
      --priority N               Windows: WinDivert handle priority, -30000..30000 (default 0)
      --pcap FILE                write the packets the engine releases to a pcap file
  -c, --control ADDR             control socket: unix:/path, tcp:PORT or tcp:HOST:PORT
      --control-token TOKEN      clients must send this token (or set GENEVA_CONTROL_TOKEN)
  -e, --events SINK              JSON Lines events: - (stdout), stderr, FILE or none
      --stats-interval SEC       emit a stats event every SEC seconds (default 10 with --events)
      --duration SEC             stop after SEC seconds
      --queue-maxlen N           packets the kernel may hold for us (default 4096)
      --max-delayed N            delayed packets (sleep) kept at once (default 1024)
      --rng-seed N               seed for random values (reproducible runs)
  -l, --log-level LEVEL          error, warn, info (default), debug or trace
      --log-format FMT           text (default) or json
      --log-file FILE            also write the log to FILE
  -v, --verbose                  log every packet (same as --log-level trace)
      --quiet                    no log on stderr
  -h, --help                     show help
