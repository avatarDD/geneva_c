### usage
$ $G
geneva VERSION - genetic censorship evasion (C port of Geneva)

Usage: geneva <command> [options]

Commands:
  agent      run the probes of a server-side evaluation (no root)
  apply      run a strategy over a pcap file offline
  censor     run one of Geneva's lab censors on a Linux router
  check      parse, validate and print strategies
  ctl        talk to a running engine over its control socket
  db         list, rank, export and prune the strategy database
  eval       evaluate strategies against a target with a probe
  evolve     search for strategies with the genetic algorithm
  fw         print, apply or remove the firewall rules of run
  library    list the built-in strategies of Geneva's library
  run        apply a strategy to live traffic (NFQUEUE, WinDivert or divert)
  version    print version and build features

Run "geneva <command> --help" for command options.
[exit 2]

      --firewall TYPE            auto, nft, iptables, or none (rules set up by hand)

Searches for strategies with Geneva's genetic algorithm, scoring each one with
a probe through the engine (root or Administrator). First checks that the probe

current step; with --checkpoint the search continues later with --resume.
Example: geneva evolve --probe http --host blocked.example --population 50

Options:
      --in-trees N               inbound trees per new strategy (default 0: no inbound forest)
      --out-trees N              outbound trees per new strategy (default 1)
      --in-actions N             actions per new inbound tree (default 2)
      --out-actions N            actions per new outbound tree (default 2)
      --fix-trigger TRIGGER      use this trigger in every tree (e.g. TCP:flags:PA)
      --seed STRATEGY            start every individual from this strategy
      --load-from FILE           start from a generation file (one strategy per line)
      --population N             population size (default 250)
      --generations N            generations to run (default 50)
      --elite-clones N           copies of the best individual kept (default 3)
      --mutation-pb P            mutation probability (default 0.99)
      --crossover-pb P           crossover probability (default 0.4)
      --allowed-retries N        times a strategy may be generated again (default 20)

Usage: geneva fw print|up|down -p PORTS [options]

      --firewall TYPE            auto, nft, iptables, ipfw, pf, or none (rules set up by hand)
  -i, --iface IF                 only traffic through this interface (the WAN on a router)
      --dir both|out|in          directions to intercept (default both)
  -4, --ipv4-only                handle IPv4 only
  -6, --ipv6-only                handle IPv6 only
      --first N                  apply the strategy to the first N packets of each connection per direction
      --prenat                   nft: intercept outgoing packets before SNAT (default after)
      --no-notrack               leave packets the engine sends in conntrack
      --no-bypass                drop instead of pass traffic while no engine listens
      --forward-to ADDR          Geneva forwarder: DNAT the ports to ADDR and masquerade
      --filter EXPR              Windows: WinDivert filter to capture, replaces the one from -p/--proto/--dir
      --filter-file FILE         Windows: read the --filter expression from FILE (up to 64 KB)
      --priority N               Windows: WinDivert handle priority, -30000..30000 (default 0)
      --local-ports BASE         the evaluator's rules (eval/evolve --firewall none): ports from BASE
      --workers N                with --local-ports: the evaluator's workers, 64 ports each (default 1)
      --probe KIND               with --local-ports: dns, exec and external probes add UDP
  -l, --log-level LEVEL          debug shows every command
  -h, --help                     show help
